# DMS Plugins

A collection of plugins for [DankMaterialShell](https://github.com/AvengeMedia/DankMaterialShell) maintained by [@hthienloc](https://github.com/hthienloc).

## Plugins

| Plugin | Type | Description |
|---|---|---|
| [Activate Linux Watermark](activateLinux) | Desktop Widget | Subtle "Activate Linux" watermark for your desktop. |
| [Ambient Sound](ambientSound) | DankBar Widget / Popout | Soothing background sounds to help you relax or focus. |
| [Bongo Cat](bongoCat) | Desktop Widget | Animated Bongo Cat reacting to typing on your desktop. |
| [Breathing Exercise](breathing) | DankBar Widget / Popout | Guided box-breathing widget for stress relief and focus. |
| [Caffeine](caffeine) | DankBar Widget / Control Center | Keep your screen awake and inhibit idle sleep. |
| [Desktop Widget Toggle](desktopWidgetToggle) | DankBar Widget | Quickly show or hide all active desktop widgets. |
| [Emoji Picker](emojiPicker) | Launcher / Popout | Fast searchable emoji picker for your workspace. |
| [Hand Mirror](handMirror) | DankBar Widget / Popout | Quick webcam preview check right from your bar. |
| [Hidden Bar](hiddenBar) | DankBar Widget | Expand and collapse extra DankBar items like macOS Hidden Bar. |
| [Hydrate](hydrate) | DankBar Widget / Popout | Water intake reminder and hydration logger. |
| [IP Indicator](ipIndicator) | DankBar Widget | Displays local/public IP address and network status. |
| [Kaomoji Picker](kaomojiPicker) | Launcher / Popout | Browse and copy text faces / kaomojis quickly. |
| [Lutris Launcher](lutrisLauncher) | Launcher | Search and launch games directly from Lutris library. |
| [Media Downloader](mediaDownloader) | DankBar Widget / Popout | Download media via yt-dlp right from the shell. |
| [Niri Display Settings](niriDS) | Settings / Control Center | Display scaling, resolution, and monitor layout for Niri. |
| [OCR Scanner](ocrScanner) | Utility | Scan screen region and extract text via Tesseract OCR. |
| [Quick Capture](quickCapture) | Daemon / Widget / Control Center | Screenshot annotation, editor, and screen recording tool. |
| [Screenkey](screenkey) | Desktop Widget | Display pressed keys and keystrokes on-screen. |
| [Take a Break](takeABreak) | DankBar Widget / Popout | 20-20-20 eye strain reminder and break timer. |
| [Timer](timer) | DankBar Widget / Popout | Countdown timer with presets and notifications. |
| [Typing Sounds](typingSounds) | Daemon | Satisfying mechanical keyboard sounds on keypress. |
