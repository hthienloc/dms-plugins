# DMS Plugins

A collection of plugins for [DankMaterialShell](https://github.com/AvengeMedia/DankMaterialShell) maintained by [@hthienloc](https://github.com/hthienloc).

## Plugins

| Plugin | Type | Description |
|---|---|---|
| [Activate Linux Watermark](activateLinux) | Desktop Widget | Display Windows-style "Activate Linux" watermark on your desktop. |
| [Ambient Sound](ambientSound) | DankBar Widget / Popout | Play ambient background sounds for focus and relaxation. |
| [Bongo Cat](bongoCat) | DankBar Widget | Reactive Bongo Cat in your bar that taps paws as you type. |
| [Breathing Exercise](breathing) | DankBar Widget / Popout | Guided breathing techniques and exercises for relaxation and focus. |
| [Caffeine](caffeine) | DankBar Widget / Control Center | Keep your screen awake and prevent idle sleep with duration presets. |
| [Desktop Widget Toggle](desktopWidgetToggle) | Composite (Daemon / DankBar Widget) | Toggle visibility of desktop widget groups as an overlay. |
| [Emoji Picker](emojiPicker) | Daemon (Modal Picker) | Centered modal emoji picker triggered via IPC or shortcut. |
| [Hand Mirror](handMirror) | DankBar Widget / Popout | Quick webcam preview check right from your bar. |
| [Hidden Bar](hiddenBar) | DankBar Widget | Expand and collapse extra DankBar items like macOS Hidden Bar. |
| [Hydrate](hydrate) | DankBar Widget / Popout | Water intake reminder and hydration tracking dashboard. |
| [IP Indicator](ipIndicator) | DankBar Widget / Popout | Display local/public IP address, ISP, and network location. |
| [Kaomoji Picker](kaomojiPicker) | Launcher | Search and copy Japanese emoticons (kaomojis) directly from DMS launcher. |
| [Lutris Launcher](lutrisLauncher) | DankBar Widget / Popout | Browse and launch Lutris games from a visual bar popout grid. |
| [Media Downloader](mediaDownloader) | DankBar Widget / Popout | Download media via yt-dlp right from the shell. |
| [Niri Display Settings](niriDS) | Composite (Daemon / Control Center) | Manage display scaling, resolution, and monitor profile layout for Niri. |
| [OCR Scanner](ocrScanner) | DankBar Widget / Popout | Extract text from screen regions or clipboard images using Tesseract OCR. |
| [Quick Capture](quickCapture) | Composite (Daemon / Widget / Control Center) | Screenshot annotation, editor, and screen recording tool. |
| [Screenkey](screenkey) | Composite (Daemon / Control Center) | On-screen keystroke and click visualizer with Control Center toggle. |
| [Take a Break](takeABreak) | Composite (Daemon / Control Center) | 20-20-20 eye strain reminder with break overlay and Control Center toggle. |
| [Timer](timer) | DankBar Widget / Popout | Countdown timer with presets, notifications, and timeout actions. |
| [Typing Sounds](typingSounds) | Composite (Daemon / Control Center) | Play mechanical keyboard sounds globally as you type with Control Center toggle. |
