# DMS Plugins

A collection of plugins for [DankMaterialShell](https://github.com/AvengeMedia/DankMaterialShell) maintained by [@hthienloc](https://github.com/hthienloc).

## Plugins

| Plugin | Type | Description |
|---|---|---|
| [Activate Linux Watermark](plugins/activateLinux) | Desktop Widget | Subtle "Activate Linux" watermark for your desktop. |
| [Ambient Sound](plugins/ambientSound) | DankBar Widget / Popout | Soothing background sounds to help you relax or focus. |
| [Bongo Cat](plugins/bongoCat) | Desktop Widget | Animated Bongo Cat reacting to typing on your desktop. |
| [Breathing Exercise](plugins/breathing) | DankBar Widget / Popout | Guided box-breathing widget for stress relief and focus. |
| [Caffeine](plugins/caffeine) | DankBar Widget / Control Center | Keep your screen awake and inhibit idle sleep. |
| [Desktop Widget Toggle](plugins/desktopWidgetToggle) | DankBar Widget | Quickly show or hide all active desktop widgets. |
| [Emoji Picker](plugins/emojiPicker) | Launcher / Popout | Fast searchable emoji picker for your workspace. |
| [Hand Mirror](plugins/handMirror) | DankBar Widget / Popout | Quick webcam preview check right from your bar. |
| [Hidden Bar](plugins/hiddenBar) | DankBar Widget | Expand and collapse extra DankBar items like macOS Hidden Bar. |
| [Hydrate](plugins/hydrate) | DankBar Widget / Popout | Water intake reminder and hydration logger. |
| [IP Indicator](plugins/ipIndicator) | DankBar Widget | Displays local/public IP address and network status. |
| [Kaomoji Picker](plugins/kaomojiPicker) | Launcher / Popout | Browse and copy text faces / kaomojis quickly. |
| [Lutris Launcher](plugins/lutrisLauncher) | Launcher | Search and launch games directly from Lutris library. |
| [Media Downloader](plugins/mediaDownloader) | DankBar Widget / Popout | Download media via yt-dlp right from the shell. |
| [Niri Display Settings](plugins/niriDS) | Settings / Control Center | Display scaling, resolution, and monitor layout for Niri. |
| [OCR Scanner](plugins/ocrScanner) | Utility | Scan screen region and extract text via Tesseract OCR. |
| [Quick Capture](plugins/quickCapture) | Daemon / Widget / Control Center | Screenshot annotation, editor, and screen recording tool. |
| [Screenkey](plugins/screenkey) | Desktop Widget | Display pressed keys and keystrokes on-screen. |
| [Take a Break](plugins/takeABreak) | DankBar Widget / Popout | 20-20-20 eye strain reminder and break timer. |
| [Timer](plugins/timer) | DankBar Widget / Popout | Countdown timer with presets and notifications. |
| [Typing Sounds](plugins/typingSounds) | Daemon | Satisfying mechanical keyboard sounds on keypress. |
